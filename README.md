# Portfolio Website

Modern portfolio website built with Next.js 16.

🔗 **Live Site:** [marawaneldeib.com](https://marawaneldeib.com/en)

## Tech Stack

**Framework:** Next.js 16, TypeScript
**Styling:** Tailwind CSS 4, Framer Motion
**Email API:** Resend
**Deployment:** Vercel
**i18n:** next-intl
**UI:** Lucide React, React Hook Form
